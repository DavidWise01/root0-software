**Doubt Ladder:** Primitive `0 . 0` · Ladder `1→3→5→7→9→11` · Ground `000|1`

The doubt ladder is the ascending odd-integer sequence that bridges zero to certainty. Each rung is a decision threshold. Ground state `000|1` is the minimum viable truth signal.
